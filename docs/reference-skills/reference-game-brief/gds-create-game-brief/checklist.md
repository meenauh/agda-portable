# Game Brief Validation Checklist

Use this checklist to ensure your game brief is complete and ready for systems mapping.

## Game Vision ✓

- [ ] **Core Concept** is clear and concise (one sentence)
- [ ] **Elevator Pitch** hooks the reader in 2-3 sentences
- [ ] **Vision Statement** is aspirational but achievable
- [ ] Vision captures the emotional experience you want to create

## Player and Experience Fit ✓

- [ ] **Intended Player Experience** is specific enough to guide design
- [ ] **Primary Player Motivation** is clear
- [ ] Play session expectations are realistic
- [ ] **Not For** boundaries are explicit
- [ ] **First Game Validation** is practical

## Game Fundamentals ✓

- [ ] **Primary Mechanics** describe what players actually DO
- [ ] **Player Experience Goals** connect mechanics to emotions

## Scope and Constraints ✓

- [ ] **Target Platforms** are prioritized
- [ ] **Technical Constraints** are identified
- [ ] Scope matches production constraints

## Reference Framework ✓

- [ ] **Inspiration Games** (3-5) are listed with specifics
- [ ] You know what you're taking vs. NOT taking from each
- [ ] **Design Neighbors** clarify nearby references
- [ ] **Key Differentiators** are genuine and visible in play
- [ ] Differentiators are specific (not "just better")

## Content Framework ✓

- [ ] **World and Setting** is defined at a useful high level
- [ ] **Narrative Approach** matches game type
- [ ] **Content scale** is described broadly enough to expose scope risk
- [ ] Replayability approach is clear

## Art and Audio Direction ✓

- [ ] **Visual Style** is described with references
- [ ] 2D vs. 3D is decided
- [ ] **Audio Style** matches game mood
- [ ] **Production Approach** is realistic for the pipeline
- [ ] Style complexity matches capabilities

## Risk Assessment ✓

- [ ] **Key Risks** are honestly identified
- [ ] **Technical Challenges** are documented
- [ ] **Experience Validation Risks** are considered
- [ ] **Mitigation Strategies** are actionable
- [ ] Assumptions to validate are listed

## Core Loop Design ✓

- [ ] Moment-to-moment loop is intrinsically satisfying
- [ ] Short-term loop creates clear repeatable goals
- [ ] Session loop has a stopping point and return hook
- [ ] Long-term progression is defined
- [ ] Core loop validation question is explicit

## MDA and Player Motivation ✓

- [ ] Top target aesthetics are identified
- [ ] Intended dynamics are mapped to mechanics
- [ ] Autonomy, competence, and relatedness are checked
- [ ] Flow-state notes are practical

## Pillars and Anti-Pillars ✓

- [ ] 3-5 pillars are defined
- [ ] Each pillar has a concrete design test
- [ ] Anti-pillars define tempting things the game will not do
- [ ] Pillar conflict priority is clear

## Scope Feasibility and MVP ✓

- [ ] Target platform is captured
- [ ] Engine/framework preference is captured or marked undecided
- [ ] Art pipeline and broad content scale are realistic
- [ ] MVP tests the core loop
- [ ] Scope tiers and cut lines are explicit

## Next AGDA Stage ✓

- [ ] **Non-goals** are explicit
- [ ] **Risks** are documented
- [ ] Required decisions have been resolved during the process
- [ ] Systems mapping is the clear next stage
- [ ] Blockers are identified

## Overall Quality ✓

- [ ] Brief is clear and concise (3-5 pages)
- [ ] Sections are internally consistent
- [ ] Scope is realistic for production constraints and timeline
- [ ] Vision is compelling and achievable
- [ ] You're excited to build this game
- [ ] The vision is understandable without extra explanation

## Red Flags 🚩

Watch for these warning signs:

- [ ] ❌ Scope too large for production timeline
- [ ] ❌ Unclear core loop or pillars
- [ ] ❌ Intended player experience is "everyone"
- [ ] ❌ Differentiators are vague or weak
- [ ] ❌ No prototype plan for risky mechanics
- [ ] ❌ Timeline or production capacity is wishful thinking
- [ ] ❌ Nearby games are copied without a clear design promise
- [ ] ❌ MVP is not actually minimal

## Ready for Next Stage?

If you've checked most boxes and have no major red flags:

✅ **Ready to proceed to:**

- Systems mapping

⚠️ **Need more work if:**

- Multiple sections incomplete
- Red flags present
- Core concept unclear

---

_This checklist is a guide, not a gate. Use your judgment based on project needs._
